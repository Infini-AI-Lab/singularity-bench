# Word count

Implement `count_words(text)` in `/app/solution.py`. It returns a dictionary that maps each word of `text` to the
number of times it occurs. A word is a whitespace-separated piece of `text`, lower-cased, with the punctuation
characters of Python's `string.punctuation` removed from both ends; pieces that are empty after that are not words.

Your function is evaluated on texts you do not see. Use only the Python standard library, and do not read or write
files outside `/app`.
